# Portfolio di Giovanni Criscione

Sito statico essenziale per una lettura rapida. Nessuna dipendenza di build o font esterni.

## Anteprima locale

Apri `index.html` nel browser oppure, da questa cartella, avvia un server HTTP:

```powershell
python -m http.server 8000
```

Visita `http://localhost:8000`.

## Aggiornare il sito

- `index.html`: profilo, esperienza, formazione, competenze, contatti e metadati.
- `assets/css/styles.css`: aspetto, layout responsive e temi.
- `assets/js/app.js`: menu mobile, cambio tema e anno corrente.
- `documents/Giovanni_Criscione_CV.pdf`: documento scaricabile.

I contenuti pubblicati derivano dal CV fornito il 18 ottobre 2026. Aggiorna prima di tutto il testo sintetico iniziale e le esperienze quando cambia il tuo percorso. Aggiungi una sezione progetti solo quando hai lavori documentabili e link pubblici.

## GitHub Pages

In **Settings → Pages**, seleziona **Deploy from a branch**, il branch da pubblicare e la cartella **/(root)**. I percorsi degli asset sono relativi e funzionano anche quando il sito è servito da una sottocartella.

Prima di pubblicare, verifica che il CV incluso e i recapiti siano quelli che vuoi rendere pubblici.
